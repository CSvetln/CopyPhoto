#Пет-проект синхронизации фотографий 

Приложение создано для копирования файлов с фотоаппарата и смартфона

Для копирования файлов с телефона надо подключить телефон по usb, на телефоне включить режим разработчика и разрешить отладку по usb.

Данное приложение использует для копирования файлов со смартфона инструмент для отладки и работы с консолью Android  - ADB (Android Debug Bridge). 
Для начала работы с ADB необходимо:
1. Активация на устройстве: Настройки - Для разработчиков(если этот пункт скрыт, нажми семь раз на номер сборки в меню «О телефоне») -  Включить «Отладка по USB».
2. Для установки ADB на компьютер скачиваем Adb Kit и распаковываем в любую папку. Работать с adb нужно из командной строки. Нажимаем Win + R и вводим cmd, далее переходим в папку, в которой лежит adb. В данном случае это каталог "C:\platform-tools". Чтобы не проделывать этот шаг много раз, путь к ADB был прописан в переменную среды.

Если планируется синхронизация со смартфона поставьте галочку "Синхронизация с телефона", тогда не нужно прописывать "Каталог для синхронизации(фотоаппарат)". "Каталог для синхронизации(носитель)" - это пусть с которым будет идти сравнение сущестуют ли на компьютере уже такие фотограции. Расширение файла указывает формат файлов для копирования. 

Алгоритм работы кнопки "Синхронизировать последние файлы":
1. Если последняя дата не указана на форме, она ищется в папке назначения(""E:\\Фотографии"). Берется дата последней папки.
2. Если включена галочка "Синхронизация с телефона", создается список всех файлов в папке /sdcard/DCIM/Camera/ смартфона с указанным расширением  у которых дата создания(дата создания указана в названии файла) больше указанной. В противном случае, создается список файлов с флешки фотоаппарата по указанному в поле "Каталог для синхронизации(фотоаппарат)" пути, у которых дата создания больше указанной.
3. Для всех найденных в 2 пункте файлов создается папка "E:\\тест\\yy.MM.dd" и файлы в нее.


Алгоритм работы кнопки "Синхронизировать все файлы":
1. Если включена галочка "Синхронизация с телефона", создается список всех файлов в папке /sdcard/DCIM/Camera/ смартфона с указанным расширением. В противном случае, создается список файлов с флешки фотоаппарата по указанному в поле "Каталог для синхронизации(фотоаппарат)" пути.
2. Создается список файлов существующих на компьютере по пути указанному в поле "Каталог для синхронизации(носитель)".
3. Для всех найденных в 1 пункте файлов проверяется есть они в существующих, если нет - создается папка "E:\\тест\\yy.MM.dd" и файлы, которых нет на компьютере, копируются в нее.
